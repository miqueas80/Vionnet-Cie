SUBIDA A GITHUB PAGES
1. Subí SOLO el archivo index.html a la raíz del repositorio.
2. Si ya existe otro index.html, reemplazalo.
3. Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Actualizá la página con Ctrl+F5 o borrá la caché del navegador.

Esta versión tiene las imágenes de París integradas dentro del propio HTML,
por lo que no depende de la carpeta images y no deberían aparecer imágenes rotas.
